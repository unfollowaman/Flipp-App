Flipp Android Privacy Policy

Effective date: November 27, 2026

This policy describes how the Flipp Android app handles information when you use its PDF and image tools. It applies to the app named Flipp. It does not describe Android, a document provider, or another service that you choose to use with your files.

Information Flipp processes

When you choose a file, Flipp reads the file content needed for the tool you selected. The app may also read the selected file's display name and size to show it in the interface. Depending on the tool, you may enter text, page ranges, formatting choices, a PDF password, or a signature, or choose an image to use as a signature or watermark. Flipp processes these items locally to create the result you request.

Flipp does not require an account and does not keep a document history or a database of your files. The app's source manifest requests no permissions. The merged release manifest includes an app-scoped signature permission contributed by AndroidX Core, but no INTERNET or broad storage permission. Android's document picker grants access to the files you select. The app does not transmit selected file contents, passwords, signatures, or extracted text to Flipp or to a Flipp server.

File selection and saving

Flipp uses Android's Storage Access Framework and system document picker for you to select input files and choose where to save outputs. The app receives access to the files you select for the requested operation. If you select a file from, or save a result through, a cloud or other third-party document provider, that provider may transfer, store, or otherwise process the file under its own privacy policy and settings. Those provider practices are separate from Flipp.

Temporary files, retention, and deletion

Some tools create temporary output or intermediate files in Flipp's app-private cache while processing. The app deletes temporary files along some workflow reset and cleanup paths, and clears a subset of known scratch-file names at launch. Cleanup is best-effort: if a process is interrupted, cleanup fails, or the app stops unexpectedly, a temporary file may remain in the cache until Android removes cached data or you clear Flipp's app storage. Flipp does not promise that every temporary file is deleted immediately after a result is saved.

Android backup is disabled for Flipp, and the app's backup and device-transfer rules exclude app data. Files that you save through a document provider are subject to the retention and deletion controls of the destination you chose.

Clipboard

The PDF-to-text tool can copy extracted text to the Android system clipboard when you tap its copy action. The text remains subject to Android's clipboard behavior and your device settings; other apps may be able to access clipboard content as allowed by Android.

Diagnostics and third-party code

Flipp uses Android system logging for diagnostic messages and exceptions. A log entry may include technical error details or a stack trace. The app has no INTERNET permission with which to send these logs. Android or device-maker diagnostic features are controlled separately by your device and its settings.

The app's Gradle dependency declarations include AndroidX, Kotlin coroutines, iTextG, and SpongyCastle for the interface, local processing, PDF handling, and encryption. Those declarations do not list an analytics, advertising, or crash-reporting SDK.

Security

File processing happens on your device. App-private cache files are protected by Android's app storage boundaries, but device access, Android settings, and any document provider you choose affect the security of files outside Flipp. The password-protection tool creates a password-protected PDF locally; keep your password safe because Flipp does not keep a copy for recovery.

Changes to this policy

If Flipp's data handling changes, this policy will be updated to describe the new behavior. Check the effective date above when reviewing this page.

Contact

For questions about this policy or Flipp's privacy practices, contact the app developer using the contact details shown in the Developer contact section of Flipp's Google Play listing.
